## GETTING STARTED

### Launching the Application
1. **Standalone Version**: Double-click `BatchRenamer.exe`
2. **Python Version**: Run `python BatchRenamer.py` (requires Python 3.8+)

### Initial Setup
1. Click **"Browse"** to select your target folder
2. Choose between **📄 File** or **📁 Folder** mode using the radio buttons
3. The file list will automatically populate with a live preview

## CORE RENAMING MODES

### 1. 🆕 New Name & Serial Tab
**Perfect for: Product catalogs, photo sequences, organized collections**

- **Common Name**: Base name for all files (e.g., "Vacation_")
- **Serial Number**: 
  - ✅ Enable/disable with the "Serial" checkbox
  - **Start From**: Beginning number (1, 100, etc.)
  - **Position**: Before or after the common name
  - **Format**: 
    - Numeric: 1, 01, 001, 0001
    - Letters: A, a (A, B, C... Z, AA, AB...)
    - Roman: I, i (I, II, III, IV...)

*Example: "Photo_001.jpg", "Photo_002.jpg"*

### 2. 🔤 Character Cleanup Tab
**Perfect for: Fixing messy filenames, removing special characters**

- **Characters to Remove**: Specific characters to delete
- **Replace With**: Replacement character (space, dash, or remove entirely)
- **✅ Auto Cleanup**: Automatically removes multiple spaces, dots, and symbols

*Example: "file--name..jpg" → "file-name.jpg"*

### 3. 📝 Word Cleanup Tab
**Perfect for: Removing watermarks, brand names, unwanted text**

- **Words to Remove**: Comma-separated list (e.g., "copy, watermark, draft")
- **Replace With**: Replacement text
- **Conflict Symbol**: Character added if name conflicts occur (default: $)

*Example: "document_copy_final.pdf" → "document_final.pdf"*

### 4. 🎯 Pattern Tab (NEW)
**Perfect for: Professional workflows, metadata-based naming**

Insert placeholders using the **"Insert Placeholder ▼"** button:

**Basic Placeholders:**
- `{name}` - Original filename
- `{ext}` - File extension
- `{counter}` - Sequential number
- `{random_str}` - Random 4-character string

**File Metadata:**
- `{size_kb}` - File size in KB
- `{date_modified}` - Last modified date
- `{parent_folder}` - Containing folder name

**Date & Time:**
- `{year}`, `{month_Jan}`, `{month_01}`, `{day}`
- `{time_24hr}`, `{time_12hr}`
- Presets: `{Date_YMD}`, `{Timestamp1}`, etc.

**Media Metadata** (if available):
- `{date_taken}`, `{camera_model}`, `{width}x{height}`
- `{artist}`, `{title}`, `{album}`

*Example Pattern: `{parent_folder}_{year}_{counter}{ext}`  
Result: `Vacation_2024_001.jpg`*

### 5. 📊 CSV-Based Tab (NEW)
**Perfect for: Bulk operations, spreadsheet integration**

1. Click **"Import CSV"** to load your spreadsheet
2. Select the appropriate **Column** containing new names
3. Files will match based on original names or fuzzy matching

**CSV Format:**
```
original_name,new_name
IMG_1234.jpg,Product Shot A.jpg
document.pdf,Processed Document.pdf
```

## ADVANCED FEATURES

### 📁 Dual Mode Operation
- **File Mode**: Traditional file renaming with file type filtering
- **Folder Mode**: Rename entire folders and subfolders

### 🎨 Theme System
- Toggle between **Dark** (default) and **Light** themes
- Use `Ctrl+D` or click the theme button (🌙/🔅)

### 🔍 Smart Selection & Filtering
- **Checkbox System**: Select individual files to rename
- **Search Box**: Filter files by name in real-time
- **Status Filter**: Show only Changed, Conflict, or Unchanged files

### 📈 File Statistics (NEW)
Click the **"📊"** button for comprehensive analytics:
- **Storage Summary**: Total size, file counts, average sizes
- **File Type Analysis**: Breakdown by extension and category
- **Size Distribution**: Visual charts of file sizes
- **Content Analytics**: Media files, documents, and efficiency metrics

### 💾 Export Capabilities
- **Export CSV**: Save rename previews for documentation
- **Copy Names**: Right-click any file to copy its name

## BEST PRACTICES

### 🛡️ Safety First
1. **Always Preview**: Use the live preview to verify changes
2. **Selective Renaming**: Use checkboxes to rename only specific files
3. **Test with Copies**: Enable "Save in Folder" when testing new patterns
4. **Backup Important Files**: Keep backups before major operations

### ⚡ Efficiency Tips
1. **Use Patterns** for consistent, metadata-driven naming
2. **Leverage CSV** for large, predefined rename operations
3. **Combine Methods**: Use character cleanup with serial numbering
4. **Save Configurations**: Note successful pattern combinations for reuse

### 🔧 Advanced Workflows
1. **Photo Organization**: Use `{date_taken}_{camera_model}_{counter}`
2. **Document Management**: `{year}-{month_01}-{day}_{parent_folder}_{name}`
3. **Product Catalogs**: `Product_{counter}_{size_kb}KB{ext}`
4. **Archive Preparation**: `{year}_{random_str}_{original_name}`

## TROUBLESHOOTING

### Common Issues
- **Icons Not Showing**: Ensure `resources/` folder is in the same directory as `.exe`
- **CSV Import Fails**: Verify CSV format and column selection
- **Patterns Not Working**: Check placeholder syntax and available metadata
- **Undo Not Available**: Undo only works for the most recent operation

### Performance
- **Large Folders**: Application handles thousands of files efficiently
- **Live Preview**: May slow with 10,000+ files - use filters to manage
- **Memory Usage**: Optimized for typical usage scenarios
