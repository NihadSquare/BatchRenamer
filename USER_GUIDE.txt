## INTRODUCTION

Batch Renamer v2.6.2 is a comprehensive file renaming tool that allows you to rename multiple files simultaneously with advanced features like real-time preview, dark/light themes, advanced filtering, undo/redo support, and much more. This guide will help you master all the features efficiently.

---

## GETTING STARTED

### 🚀 Launching the Application
1. **Double-click** `BatchRenamer_v2.6.2.exe` (no installation required)
2. The application opens with **Dark Theme** by default
3. Use the **🌙/🔅** button to toggle between dark and light themes

### 📁 Selecting Files
1. Click **"Browse"** to select your target folder
2. The folder path will display in the top entry field
3. Files from the selected folder will appear in the preview panel

## FEATURES & OPTIONS

### 🎯 SECTION 1: FOLDER SELECTION
- **Browse Button**: Select your target folder
- **✅ Include Subfolders**: Toggle to process files in subdirectories
- **✅ Save in Folder**: Creates copies in "RenamedFiles" folder instead of modifying originals

### 🔧 SECTION 2: CHARACTER CLEANUP
**Character-Based Operations:**
- **Characters to Remove**: Enter characters to delete (e.g., `-_`)
- **Replace With**: What to replace them with (e.g., space)
- **Auto Cleanup**: Automatically removes multiple spaces/dots/symbols

**Word-Based Operations:**
- **Words to Remove**: Enter comma-separated words (e.g., `copy, image, photo`)
- **Replace With**: Replacement text for removed words
- **Conflict Symbol**: Symbol added if name conflicts occur (default: `$`)

### 🏷️ SECTION 3: NEW NAMING OPTIONS
**Common Name:**
- Replaces all filenames with your specified name
- Combine with serial numbers for organized naming

**Serial Numbering:**
- **Add Serial**: Enable sequential numbering
- **Start From**: Set starting number (e.g., 1, 100)
- **Position**: Choose "Before" or "After" the name
- **Format**: Select padding format (1, 01, 001, 0001)

### ⚙️ SECTION 4: FILE TYPE AND FILTERS
**File Types Filter:**
- **All Files**: Process every file type
- **Specific Extensions**: Filter by .png, .jpg, .pdf, .docx, etc.

**Case Conversion:**
- **No Change**: Keep original case
- **lowercase**: Convert all to lowercase
- **UPPERCASE**: Convert all to uppercase
- **Title Case**: Capitalize Each Word
- **Sentence case**: Capitalize first letter only

**Extension Changing:**
- Convert all files to selected extension
- Options: .jpg, .png, .txt, .pdf, etc.

**Skip System Files:**
- Enabled by default to protect hidden/system files

## WORKFLOW & BEST PRACTICES

### 🔄 Recommended Workflow
1. **Select Folder** → Choose your target directory
2. **Configure Options** → Set up renaming rules
3. **Preview** → Review changes in real-time
4. **Execute** → Click "Rename 🚀" to apply
5. **Verify** → Check results and use Undo if needed

### ✅ Best Practices
- **Always preview** before renaming to avoid unwanted changes
- **Use "Save in Folder"** when testing to preserve originals
- **Start with small batches** when trying new rules
- **Keep backups** of important files before bulk operations
- **Use file type filtering** to target specific file types

## TROUBLESHOOTING

### ❌ Common Issues & Solutions

**"No files found matching your criteria"**
- Check file type filter settings
- Verify folder contains files of selected types
- Ensure "Include Subfolders" is enabled if needed

**"Failed to rename" errors**
- File might be open in another program
- Check file permissions
- Try using "Save in Folder" option

**Preview not updating**
- Ensure folder is selected
- Check filter criteria aren't too restrictive
- Use Reset button and reconfigure

**Undo/Redo not working**
- Only available after successful rename operations
- Previous sessions cannot be undone after app restart
